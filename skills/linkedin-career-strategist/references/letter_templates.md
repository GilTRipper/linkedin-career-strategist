# Каркасы писем и сообщений

Это каркасы, а не готовые тексты. Каждую скобку заполняй фактами пользователя и деталями из вакансии или сайта. Если для скобки нет факта, спроси у пользователя, а не придумывай.

## 1. Сообщение в LinkedIn нанимающему менеджеру (300–600 символов)

```
[Имя], [конкретный факт о команде или продукте: запуск, статья, доклад, вакансия] — [одна фраза, почему это зацепило].

Я [роль], [конкретный результат с цифрой, близкий к их задаче].

[Гипотеза: похоже, вам сейчас нужно X / вы решаете Y — коротко].

Если интересно, могу за 15 минут рассказать, как мы делали [то же самое]. Резюме пришлю, если удобно.
```

## 2. Сообщение рекрутеру (300–500 символов)

```
[Имя], увидел вакансию [роль] в [компания]. Подхожу по [2 ключевых требования из вакансии]: [доказательство с цифрой].

[Формат/локация/сроки — одна строка, если важно].

Подскажите, к кому лучше обратиться по команде, или могу отправить CV вам?
```

## 3. Письмо нанимающему менеджеру — Pain Letter (120–200 слов)

```
Тема: [конкретика, не «Отклик на вакансию»] — например «Миграция платежей на Kafka: опыт из [компания]»

[Имя],

[Крючок: факт о компании из сайта или новостей, 1 предложение].

[Гипотеза боли: что, вероятно, сейчас тяжело команде, 1–2 предложения, со ссылкой на вакансию или факт].

[История: где ты решал похожее; что было, что сделал, какой результат в цифрах, 2–3 предложения].

[Мост: почему это переносится на их задачу, 1 предложение].

[Мягкий финал: предложение короткого созвона, без давления].

[Имя Фамилия]
[LinkedIn] · [телефон]
```

## 4. Cover letter в форму отклика (150–250 слов)

```
[Имя или команда, если имени нет — без «Dear Hiring Manager»],

[Почему именно эта роль и компания: одна конкретная деталь из вакансии или сайта].

[Главная история с цифрой, напрямую про главное требование вакансии].

[Второе требование: короткое доказательство].

[Если есть пробел: честно и коротко — что есть смежного и как быстро закроешь].

[Финал: что готов обсудить, как связаться].
```

## 5. Follow-up через 5–7 рабочих дней без ответа

```
[Имя], возвращаюсь к сообщению про [роль]. [Одна новая деталь: релевантный кейс, ссылка на работу, мысль по их продукту]. Если сейчас не до этого — понял, спасибо.
```

## 6. Просьба о реферале у знакомого или бывшего коллеги

```
[Имя], привет. Смотрю на [роль] в [компания] — [ссылка]. Ты там [в команде X / давно], поэтому решил спросить.

Подхожу по [2 пункта с доказательствами]. Если считаешь уместным, сможешь передать моё CV или подсказать, с кем поговорить? Если нет — без проблем, расскажи хотя бы, как там с [вопрос про команду].
```
